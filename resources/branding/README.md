# Litovle.cz logo

`litovle_logo_current.png` is a raster export of the current site header logo,
`../litovle.cz/assets/img/logo_cele.svg` (source SHA-256:
`1ca5b93c25b3afd7054cee129cb1f92cfc6a58af4b3edcb3395ab4878da90f3e`).
The SVG viewport was widened for export so the subtitle is fully visible;
the artwork itself was not redrawn. The renderer only scales and pastes this PNG.
